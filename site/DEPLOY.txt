Teqnowebs plain PHP — Hostinger
================================
1. Unzip on the server.
2. Point domain document root to the /public folder.
3. Copy config.local.example.php → config.local.php
   (place it next to config.php, NOT inside public/).
4. Fill MySQL details + app_url.
5. Make sure storage/ is writable.
6. Open the site — DB tables and seed users create automatically.
