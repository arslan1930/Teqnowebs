Teqnowebs plain PHP — fix 403 on Hostinger
==========================================

MOST COMMON 403 CAUSE:
  You left files inside a nested /public folder.
  Hostinger public_html/ then has no index.php → 403.

CORRECT UPLOAD:
  1. Empty (or backup) public_html/
  2. Unzip so these sit DIRECTLY in public_html/:
       index.php
       .htaccess
       assets/
       app/
       views/
       config.php
       storage/
  3. public_html/index.php must exist (open File Manager and check).
  4. Copy config.local.example.php → config.local.php
     Set MySQL details + app_url = https://teqnowebs.com
  5. storage/ folder permissions: 755 (or 775)

WRONG (causes 403):
  public_html/public/index.php   ← nested — do not do this
  public_html/site/index.php
